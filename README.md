# Admissions Link Summarizer Bot

A Telegram bot that turns admissions pages into structured summaries. Send it a link (a website,
an article, a university or scholarship page, a PDF, a DOCX file or a YouTube video) and it extracts
the main text and replies with a summary organised for applicants: deadlines, key points, who can
apply, costs, requirements, useful links and, always, a link to the original source.

Project rules and architecture: [ARCHITECTURE.md](ARCHITECTURE.md). Work plan: [TASKS.md](TASKS.md).

## About

University websites spread admissions information across long pages, separate PDFs and
per-semester notices, which makes it slow to work out whether a program is a good fit and when to
apply. This bot is an admissions assistant for prospective students, built mainly around
master's programs worldwide.

The user sends a link to a program page, or uploads a PDF/DOCX brochure, and the bot returns a
summary in clearly separated sections: admission requirements, application deadlines, language
proficiency requirements, required documents, tuition fees, scholarship opportunities and the
application procedure. This makes it easy to spot the relevant details, compare programs and plan
applications.

For example, for the M.Sc. in Data Science and Artificial Intelligence at Saarland University, the
bot summarises the curriculum, eligibility criteria, English language requirements, deadlines for
each intake, tuition policy and links to the official university pages. It also points out
important restrictions, such as whether the university accepts a Medium of Instruction certificate
instead of an English test score.

The summaries are designed to be verifiable:

- the bot only reports what is actually on the page; missing information is shown as "not
  specified" rather than guessed;
- every deadline comes with a verbatim quote from the source, and the code checks that the quote
  really appears in the extracted text; unconfirmed deadlines are flagged;
- useful links are limited to URLs that appear in the source, and the source link is added by the
  code, never generated by the model.

The project grew out of my own experience applying to international master's programs and the
difficulty of finding accurate admissions information across different university websites. My
friends and I used it during our own applications to research universities, check eligibility,
track deadlines and explore study options. Its goal is to make information about international
higher education more accessible and easier to understand, especially for students unfamiliar
with complex admissions procedures.

Summaries can be produced in English, Russian or Kazakh (`DEFAULT_LANG`). The bot's `/start` and
`/help` texts are currently in Russian only.

## Quick start

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env   # fill in TELEGRAM_BOT_TOKEN and ANTHROPIC_API_KEY
uv run python -m bot.main
```

Get the bot token from @BotFather in Telegram and the API key from the Anthropic Console. The `.env`
file is not committed to git.

## Answer cache

A repeated link is answered from a local SQLite file (`CACHE_DB_PATH`, `data/cache.sqlite3` by
default, not committed to git) without calling the model. The "🔄 Обновить" ("Refresh") button
under a summary reads the page again. Cache lifetime is set by `CACHE_TTL_HOURS` (24 by default;
`0` disables the cache). Only answers about public pages are stored, with no user data. The file can
be deleted at any time; the bot will recreate it. Details: the caching section ("Кэширование") of
[ARCHITECTURE.md](ARCHITECTURE.md).

## Development

```bash
uv run pytest                                   # tests
uv run ruff check . && uv run ruff format --check .
uv run mypy bot
uv run pre-commit install                       # pre-commit hooks
uv run pytest -m live -s                        # tests against the real API (use a few tokens)
uv run python -m bot.evaluation                 # quality on the reference set (uses tokens)
```

Optional extras (install as needed):

```bash
uv sync --extra browser            # Playwright for JavaScript-rendered pages
uv sync --extra youtube-fallback   # yt-dlp as a fallback for subtitles
```
