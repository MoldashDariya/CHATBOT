Fact check

A date makes it into the card only if it's in the text

The model extracts each deadline with a word-for-word quote. Then the code looks for that quote in the text it actually read. If it isn't found, the date stays, but it gets a mark and the bot tells you to check it.

Common questions

Can I apply based on the card alone?

The card helps you get the essentials fast, but check decisions against the source. Its link is always the last line, and every date has a quote that makes it easy to find on the page.

Does the bot store my data?

No. It saves only finished cards about public pages, so a repeated link opens instantly without counting toward your hourly limit. Files sent in the chat are never saved.

The website didn't open. What now?

The bot explains why: the page needs a login, the site isn't responding, or the link points somewhere else. Sending a PDF with the same information often helps. Scans without a text layer can't be read yet.

How do I change the card language?

Use the /lang command and pick English, Russian or Kazakh. Quotes and amounts stay in the source's language so you can find them on the page.
