### 1F. Саммари
- [x] 1.18 `schema.py`: pydantic-модели `Summary`, `Deadline`, `CostItem`, `Link`
- [x] 1.19 Промпты: `system.md` + `extract_scholarship.md`, `extract_university.md`, `extract_article.md`, `extract_generic.md`
  - решение: один `prompts/system.md` (правила, классы, язык) вместо отдельных `extract_*.md`:
    классификация и извлечение идут одним вызовом, подсказки по классам внутри общего промпта
- [x] 1.20 LLM-классификатор класса HTML-страницы (дешёвый вызов или объединить с извлечением)
  - решение: классификатор объединён с извлечением (`source_type` в ответе модели), отдельного вызова нет
- [x] 1.21 `summarizer.py`: вызов Claude, structured output, валидация, один retry
  - структурированный вывод через `output_config.format`; без `temperature`/`thinking` (новые модели их отвергают)
- [x] ~~1.22 Чанкинг длинных документов + merge-шаг~~ **отменено, не нужно сейчас**
  - `MAX_CHARS` (120000 знаков, ~30-50 тыс. токенов) на порядок ниже окна модели, один проход видит
    весь документ. Вернуться, если поднимут `MAX_CHARS` выше ~300 тыс. знаков или возьмут модель с малым окном
- [x] 1.23 Пост-проверки: цитаты дедлайнов есть в тексте; ссылки взяты из источника; предупреждение о прошедших датах
  - ссылка допустима, если она есть среди `links` ИЛИ среди URL текста (`find_urls`): экстрактор
    ограничивает `links` сотней, а очистка может освободить места; сравнивать по целому URL
  - сравнение цитат дедлайнов с текстом: после схлопывания пробелов и без учёта регистра
    (очиститель уже привёл текст к одному виду)
  - предупреждения из `meta`: `truncated` (текст обрезан), `pages_read < pages_total` (PDF)
- [x] 1.24 Защита от prompt injection в системном промпте + тест с «вредоносной» страницей
  - живой тест на настоящем API (`pytest -m live`): страница с двумя инъекциями отбита; модель описала
    их в `warnings`, ссылка атакующего не включена; код дополнительно вырезает URL из `warnings`

### 1G. Вывод
- [x] 1.25 `render/telegram.py`: карточка в HTML, экранирование, эмодзи-секции, пустые поля → «не указано»
  - дедлайн с `verified=False` помечать («не подтверждено цитатой источника»); `possibly_passed` → «мог пройти»
  - локализованные пометки из полей `Summary`: `dropped_links`, `truncated`, `pages_read < pages_total`
  - у каждой ссылки показывать домен: фильтр ссылок не защищает от URL, которые подсовывает сама страница
  - `costs[].amount_text` и `date_text` приходят на языке источника (так задумано), остальное на `language`
- [x] 1.26 Разбиение на сообщения ≤4096 без разрыва тегов и блоков
- [x] 1.27 Обязательная строка «🔎 Источник: URL» (тест: присутствует всегда)
- [x] 1.28 Единый обработчик ошибок с человекочитаемыми сообщениями
  - сообщения по `reason`: `InvalidURLError`/`BlockedURLError` (одно общее «ссылка недоступна», без деталей про SSRF),
    `FetchHTTPError` (401/403 → вход/платный доступ/защита от ботов), `FetchTimeoutError`, `ContentTooLargeError`,
    `UnsupportedFormatError` (`legacy_office` → пришли PDF/DOCX), `ExtractionError.reason`, `TooLittleTextError`
    (по формату), `LLMError.reason` (`llm_config` пользователю как «сервис временно недоступен», оператору в лог)
